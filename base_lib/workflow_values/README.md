# 工作流通信中的业务值

VibeFlow官方协调器传输普通JSON，数值须有限且跨语言安全；ERA原计算会保留更大的数、负零、数组空位及缺失字段。此模块在消息边界编码业务值并恢复，不改变变量类型和计算规则。格式只包含固定标记和文本，因此仍由官方接口按普通JSON传递。

支持基础值、普通对象、数组（含空位）、undefined、特殊数值和bigint；对象字段用独立记录表达，不与用户自己的键名冲突。宿主对象、函数和运行资源仍由Tavern的资源编号管理，不交给此模块序列化。循环引用不属于业务消息格式。

只有workflow之间的消息边界使用此转换；Macro等原始同步根入口保持其合同。这里不提供协调器、消息队列或第二份业务状态。
