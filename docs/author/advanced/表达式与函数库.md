# 表达式与函数库

伤害、价格和成长值适合用公式维护。`$expr`计算数值，Function标签维护可重放的表达式函数；有条件、循环、字符串或异步业务时使用[JavaScript函数](JavaScript函数调用.md)。

## 更新数值

```xml
<VariableEdit>{"era_demo":{"player":{"hp":{"$expr":"max(0, era_demo.player.hp - 3)"}}}}</VariableEdit>
```

hp从20变为17。表达式目标必须已存在，目标、输入与结果需满足有限数值要求。支持括号、正负号、`+ - * / % ^`及函数调用，不是任意JavaScript；没有 `$inc/$mul/$set` 等另一套数学更新指令。

变量引用从状态根部寻址，嵌套变量应写完整路径，如 `era_demo.rpg.gold`。`@path` 读取本条消息开始时的变量值；普通引用读取执行到当前位置的值。例如本楼先扣血，再读取起点生命计算“本轮损失”，应使用起点引用而不是已经扣过的生命。

## 维护表达式函数库

```xml
<FunctionInsert>{"damage":{"params":["attack","armor"],"expr":"max(1, attack - armor)"}}</FunctionInsert>
<VariableEdit>{"era_demo":{"player":{"hp":{"$expr":"max(0, era_demo.player.hp - damage(8, 3))"}}}}</VariableEdit>
<FunctionEdit>{"damage":{"params":["attack","armor"],"expr":"max(1, attack - armor / 2)"}}</FunctionEdit>
```

此次受到5点伤害，之后的调用使用修改后的公式。已有函数不会被FunctionInsert覆盖；删除用 `<FunctionDelete>{"damage":{}}</FunctionDelete>`。删除或修改后，整个函数库的引用仍必须有效。函数参数使用数值，函数体通过参数表达计算；不要把它当成闭包读取外部JavaScript变量。

`@damage(8,3)`使用本消息开始时的函数定义，适合“本轮中途升级装备，但本轮攻击仍采用起点规则”的情况。函数库随ERA历史保存和重放，与角色脚本的运行时工具注册不同。

函数定义可带 `$meta.updatable` 和 `$meta.necessary`，删除保护使用 `self` 或 `all`；不支持 `children` 与 `unInsertAble`。函数工作台提供搜索、表单/JSON编辑、批量函数库编辑、操作预览和试算。试算纯公式不会改变量；未绑定消息的试算需要固定随机参数。

## 随机与历史重放

| 写法            | 含义                                           | RPG例子                        |
| --------------- | ---------------------------------------------- | ------------------------------ |
| `random()`      | 当前消息身份与自动抽取序号决定的 `[0,1)` 值    | `floor(random()*6)+1` 掷六面骰 |
| `random(42)`    | 指定有限数值种子，仍用自动抽取序号             | 为商店库存设固定种子           |
| `random(42, 0)` | 固定种子及非负安全整数抽取序号，不消耗自动序号 | 固定某件宝箱奖励的抽取         |

普通重放得到相同序列；插入更早的自动抽取会移动后续序号。需要固定某次抽取时用两个参数形式。不要用时间或 `Math.random()` 代替需要历史一致性的游戏骰点。

## 内建函数参考

三角函数以弧度计算。下列字母是公式的数值参数；使用时定义为函数形参或替换为已有数值路径。

| 函数                               | RPG用途示例                                    |
| ---------------------------------- | ---------------------------------------------- |
| `abs(x)`                           | 计算声望与目标值的距离                         |
| `floor(x)`、`ceil(x)`              | 奖励向下取整、所需口粮向上取整                 |
| `round(x)`、`trunc(x)`             | 价格四舍五入、截去计时小数                     |
| `min(a,b,...)`、`max(a,b,...)`     | 限制恢复量、确保最低伤害                       |
| `clamp(x,lo,hi)`                   | 把生命限制在0和最大生命之间                    |
| `pow(x,y)`、`sqrt(x)`              | 等级成长、递减收益                             |
| `mod(x,y)`                         | 天数轮换到每周商店周期                         |
| `exp(x)`、`log(x)`、`ln(x)`        | 指数成长、自然对数形式的等级收益               |
| `sin(x)`、`cos(x)`、`tan(x)`       | 周期气候、昼夜亮度、视线坡度                   |
| `asin(x)`、`acos(x)`、`atan(x)`    | 从方向比例恢复角度                             |
| `sinh(x)`、`cosh(x)`、`tanh(x)`    | 非线性成长、消耗曲线、趋于饱和的士气修正       |
| `asinh(x)`、`acosh(x)`、`atanh(x)` | 反解对应成长曲线所需的属性                     |
| `factorial(n)`                     | 计算n件物品的排列数；n须为非负安全整数         |
| `gamma(x)`                         | 使用连续阶乘型曲线调整高级成长公式             |
| `derivative(f,x[,order])`          | 求成长公式在等级x处的增长率；order为正安全整数 |
| `integral(f,start,end)`            | 累计一个时间区间的持续伤害                     |
| `random([seed[,draw]])`            | 骰点和可重放掉落，见随机表                     |

例如先定义一元纯函数 `burn(t)=2*t`，`derivative(burn,3)`得到2，`integral(burn,0,3)`约为9。求导先构造导数再求值，积分采用数值计算；两者只接受已定义的一元纯函数，不能直接或间接依赖random。越出定义域、非有限结果或不能构造的导数会报告错误；不要用除零模拟业务分支。
