# ERA 角色卡作者指南

ERA 让角色卡的变量随剧情变化，并在编辑、删除或切换回复分支时重新对齐历史。推荐使用**外置状态栏**，将当前生命、金币和背包固定显示在输入框上方；长篇聊天可以另行开启**单层模式**，只显示最新 AI 回复。单层模式可选，不会删除聊天历史，也不会由外置快速初始化自动开启。

第一次制卡只需阅读[初级使用](初级使用.md)。希望每条剧情下保留对应状态栏时，选择其中的传统楼内路线。

## 把哪些资料交给 AI

制作基础卡：提供初级教程、从 ERA 取出的示例状态栏 HTML，以及你的角色设定和变量需求。改变显示结构时，再提供显示模式专题；增加购买等业务时，再提供 JavaScript 函数和 API 专题。无需一次发送全部开发文档。

本套示例共用 `era_demo.player.hp`、`era_demo.player.inventory`、`era_demo.rpg.gold`、`era_demo.rpg.food`。高级例子要求先按初级教程初始化；单独复制示例时也要先创建它使用的变量。角色脚本、世界书意图和状态栏必须使用一致路径。
