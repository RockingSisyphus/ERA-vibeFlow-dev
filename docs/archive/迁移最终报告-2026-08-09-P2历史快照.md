## 失败与恢复

- 真实 E2E 初版错误地用 SillyTavern `substituteParams` 检验 Tavern Helper `registerMacroLike`，导致宏原文未变。源码审计确认宏只在发送前/渲染钩子运行；改用真实 `generate_after_data` 后通过。这是测试方法修正，不是生产兼容降级。
- 浏览器跨 realm 的普通 JSON 对象一度被误判为 host-ref；Host 编码改为先 `structuredClone` 再做 JSON 判定，加入 null-prototype 回归测试。
- forceSync 与 API write 的执行 state 数据旁路曾缺失；按正式 workflow 边补齐后，G3/G4 生成物探针和真实 Tavern 全 API 通过。
