## 作者必须知道的业务边界

函数 commit 回执表示内存应用，不保证已经保存；保存之前强制关闭页面可能丢失纯内存请求。普通函数异常保留成功前缀，阶段候选整体撤销则撤销该候选；外部副作用不回退，函数位置 API 禁止 sync。单层模式卸载旧楼 iframe，临时表单可能丢失；外置/单层及 Agent 配置用于单角色卡。完整任务或保存窗口按既定次序保存消息与 Sidecar，不在 UI、宏或宿主特例中另建变量权威状态。
