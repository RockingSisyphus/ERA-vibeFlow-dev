# ERA 双模式快速初始化

快速操作提供两个互斥的首次初始化入口；不是模式切换或迁移工具。

| 入口 | 展示位置 | 创建的显示资源 |
| --- | --- | --- |
| 快速初始化-传统状态栏 | AI 消息楼层内 | 状态栏局部正则、开场白与后续消息占位符 |
| 快速初始化-外置状态栏 | 聊天历史与输入框之间 | 角色卡外置 HTML 配置并启用；不创建楼内正则或占位符 |

两者复用示例变量、世界书、开场白资源事务与唯一初始化标记。旧的无参数资源初始化请求仍选择传统模式。

## 作者内容和重复点击

主开场白中已存在 `<!-- ERA_DEMO_GREETING_V2_BEGIN -->` 时，两个入口都拒绝二次初始化，不执行资源写入。外置模式还会拒绝覆盖任何非空外置 HTML。不会删除已有正则、聊天记录或其他角色卡配置。

初始化保留开场白作者原文。未游玩的原始首楼沿用现有同步更新合同；多楼聊天不会被批量替换。必要资源先保存，主开场白及标记最后写入；部分失败据实返回，不通过重复点击自动覆盖已有 HTML。

## 默认外置模板

使用原生 HTML/CSS/JavaScript，蓝灰色卡片与青绿色 HP 条，无外部依赖。展示 `era_demo.player` 的姓名、等级、HP、背包，以及 `era_demo.rpg` 的金币、声望、地点、任务和危险度。不存在的字段显示“未设置”。

模板先等待 `ERA.ready()`，再使用 `ERA.subscribe()` 展示当前聊天最新状态；它不会自动提交变量。状态更新只修改文本与进度属性，不重建 iframe。外置编辑器“插入示例”和初始化调用同一模板资源。

HTML 和开关随角色卡扩展保存。没有配置的卡默认关闭。编辑自动保存，查看编辑效果需要显式刷新；分享前确认保存成功。

## 验证边界

对应真实场景：`ERA-RPG-PLAYTHROUGH-001` 使用传统楼内模式，`ERA-RPG-PLAYTHROUGH-EXTERNAL-001` 使用外置模式。两版均真实导入三阶段测试预设、游玩五轮并执行手动重生成和自动纠错；外置版不创建楼内显示，仅通过显式历史 API 核对历史业务状态。
