## 复用

- ERA Service 的既有公开 `era:*` 事件、receipt、`era:writeDone` 与 `era:queryResult` ABI；
- `ERA-Test-Harness-vibeflow-20260808` 的 V3 sandbox、Bridge、Artifact、continue-on-failure、
  `era-contract-v1` Evaluator 和现有 `ui.panel.*` 操作；

- VibeFlow Service/Macro 的现有 AOT 构建；本轮不调整 workflow、Nodeset、Capability 或 Host Extension。

## 修改

- Harness fixture schema、编译器和卡片派生器：让 `alternateGreetings` 成为受限、显式的
  `fixture.initial` 输入，并为 `UI-NAV-004` 产生真实备用开场白；
- Harness action/profile/collector 与 ERA catalog：从仅能打开/关闭面板，扩展为可验证
  快照、快捷操作、设置、主题、无障碍、生命周期和样式所有权的真实 UI 操作；
- ERA UI 表现层：修正测试需求已识别的首屏状态恢复、键盘可达性、查询关联、忙碌/防重入、
  设置失败回滚、样式隔离和窄屏适配，仍只经 Service 提交业务意图；
- 测试、使用说明、TODO、最终报告与 release 状态：以新 Artifact 为唯一验收证据。

## 删除

- 不删除公开 API、持久化 Schema、Macro ABI 或历史 Artifact；
- 不恢复旧 scheduler/dispatcher、Recorder V1/V2、历史自动比较或任何 UI 直接写业务状态的路径；
- 不把旧 Artifact 作为新 UI suite 的 oracle。

## 新增

- 单一 Harness 工作树中的多开场白 fixture 合同与真实 UI 路径；
- `era-ui-smoke`、`era-ui-functional`、`era-ui-a11y`、`era-ui-lifecycle` 等专项 suite、
  严格 action completion evidence 与当前规范 Evaluator；

- 新的可审计 UI suite Artifact 与发布判断。
