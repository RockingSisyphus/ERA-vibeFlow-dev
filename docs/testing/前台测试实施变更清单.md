# ERA 前台专项测试实施变更清单

> 状态：`complete`
> 执行授权：用户于 2026-08-20 明确要求“合并到同一工作树，并完成前台测试”。

## 复用

- ERA Service 的既有公开 `era:*` 事件、receipt、`era:writeDone` 与 `era:queryResult` ABI；
- `ERA-Test-Pack` 与 `st-test-harness` 的受限 UI driver、Browser Profile、Artifact、
  continue-on-failure 和冻结 Artifact Evaluator；
- 当前 Vue/Pinia UI、`requestEraService()` 单一 UI→Service 入口，以及已登记的 UI 测试需求；
- VibeFlow Service/Macro 的现有 AOT 构建；本轮不调整 workflow、Nodeset、Capability 或 Host Extension。

## 修改

- ERA UI 表现层：以实例会话接管热重载资源；用 owner 样式容器替代复制宿主全部
  `<style>`；用 Service 回放填充首屏；统一 receipt 超时/失败处理；以查询世代隔离
  异键迟到响应，仍只经 Service 提交业务意图；
- 专项 catalog/profile：固定桌面 1440×900 鼠标与手机触屏 375×812、320×568 及横屏；
  仅普通路径使用 4 worker，生命周期和点位命中使用 1 worker；
- 测试、使用说明、TODO、最终报告与 release 状态：以新 Artifact 为唯一验收证据。

## 删除

- 不删除公开 API、持久化 Schema、Macro ABI 或历史 Artifact；
- 不恢复旧 scheduler/dispatcher、Recorder V1/V2、历史自动比较或任何 UI 直接写业务状态的路径；
- 不把旧 Artifact 作为新 UI suite 的 oracle。

## 新增

- `app` 内 UI receipt 结算工具与 timeout 合同测试；
- 专项路径的 before/after DOM、截图、console/pageerror、receipt、settlement、公共事件与
  Tavern 状态证据；
- 对 UI 服务结算、查询竞态、手机触屏视口、热重载和样式隔离的离线与真实 Tavern 覆盖；
- 新的可审计 UI suite Artifact 与发布判断。

## 已锁定兼容边界

- 桌面只验证 1440×900 鼠标基准路径；跨设备兼容仅覆盖 375×812、320×568 及对应横屏的
  手机触屏 profile。
- 不实现或验收键盘、焦点、ARIA、读屏、浏览器缩放、reduced-motion 或 WCAG 对比度。

## 审核判断

本轮没有改变 VibeFlow AOT 图、Service Host 声明或公开 ABI，因此无可登记的
`status: "planned"` VibeFlow 节点。所有新增行为位于 Harness 测试基础设施与 app UI
表现层；其设计和验收口径已由 `ERA前台UI测试需求.md` 记录，且本次实施得到直接授权。
